### 2. **JSON 序列化/反序列化重复** ⚠️ 中优先级

**位置：** 
- `backend/app/services/supplier_service.py` (203行)
- `backend/app/api/v1/endpoints/suppliers.py` (211, 215, 224, 313, 342行)
- `backend/main.py` (71, 143, 216行)

**问题：**
- 多处直接使用 `json.loads()` 和 `json.dumps()`
- 没有统一的错误处理
- `qualification_docs` 字段的 JSON 处理逻辑分散

**建议：**
```python
# backend/app/utils/json_utils.py

def safe_json_loads(json_str: str, default=None):
    """安全的 JSON 解析"""
    if not json_str:
        return default
    try:
        return json.loads(json_str)
    except (json.JSONDecodeError, TypeError):
        return default

def safe_json_dumps(obj, default=None):
    """安全的 JSON 序列化"""
    if obj is None:
        return default
    try:
        return json.dumps(obj, ensure_ascii=False)
    except (TypeError, ValueError):
        return default
```

**优化效果：**
- 统一错误处理
- 减少重复代码
- 提高代码可维护性

### 4. **数据库查询优化** ⚠️ 中优先级

**问题分析：**
虽然已经使用了 `joinedload`，但仍有一些可以优化的地方：

**位置：**
- `backend/app/services/user_service.py` - `get_by_id` 没有加载 `roles.permissions`
- `backend/app/services/supplier_service.py` - `get_by_id` 没有预加载关联关系
- `backend/app/services/project_service.py` - 部分查询没有预加载关联数据

**建议：**
```python
# 统一使用查询工具函数
# backend/app/core/db_utils.py

from sqlalchemy.orm import joinedload, selectinload

def get_user_with_relations(db: Session, user_id: int):
    """获取用户及其关联数据"""
    return db.query(User).options(
        joinedload(User.roles).joinedload(Role.permissions)
    ).filter(User.id == user_id).first()

def get_supplier_with_relations(db: Session, supplier_id: int):
    """获取供应商及其关联数据"""
    return db.query(Supplier).options(
        joinedload(Supplier.user),
        joinedload(Supplier.audit_user)
    ).filter(Supplier.id == supplier_id).first()
```

**优化效果：**
- 减少数据库查询次数
- 提高响应速度
- 统一查询模式

### 6. **默认管理员密码硬编码** 🔴 极高优先级

**位置：** `backend/app/core/config.py` (26行)

**问题：**
```python
DEFAULT_ADMIN_PASSWORD: str = "admin123"  # 硬编码密码
```

**建议：**
```python
from pydantic import model_validator
import warnings
import os

class Settings(BaseSettings):
    DEFAULT_ADMIN_PASSWORD: Optional[str] = None
    
    @model_validator(mode='after')
    def validate_security_settings(self):
        """验证安全相关配置"""
        if not self.DEFAULT_ADMIN_PASSWORD:
            if not self.DEBUG:
                raise ValueError(
                    "生产环境必须设置 DEFAULT_ADMIN_PASSWORD 环境变量！"
                )
            else:
                warnings.warn(
                    "警告：未设置 DEFAULT_ADMIN_PASSWORD，将使用默认密码 'admin123'。"
                    "生产环境部署前必须修改！",
                    UserWarning
                )
                self.DEFAULT_ADMIN_PASSWORD = "admin123"
        return self
```

**优化效果：**
- 强制生产环境使用环境变量
- 提高安全性
- 符合安全最佳实践

### 7. **文件路径安全验证** ⚠️ 中优先级

**位置：** `backend/main.py` 文件访问路由

**问题：**
- 文件路径没有验证，可能存在路径遍历攻击风险
- 文件名没有严格验证

**建议：**
```python
from pathlib import Path
import os

def validate_file_path(upload_dir: Path, file_path: Path) -> bool:
    """验证文件路径安全性"""
    try:
        # 确保文件路径在允许的目录内
        file_path.resolve().relative_to(upload_dir.resolve())
        return True
    except ValueError:
        return False

def sanitize_filename(filename: str) -> str:
    """清理文件名，移除危险字符"""
    # 移除路径分隔符和其他危险字符
    dangerous_chars = ['/', '\\', '..', '\x00']
    for char in dangerous_chars:
        filename = filename.replace(char, '')
    return filename
```

**优化效果：**
- 防止路径遍历攻击
- 提高文件访问安全性

### 9. **统一异常处理** ⚠️ 高优先级

**问题：**
- 缺少全局异常处理器
- 异常处理逻辑分散
- 错误响应格式不统一

**建议：**
```python
# backend/app/core/exceptions.py

from fastapi import Request, status
from fastapi.responses import JSONResponse
from fastapi.exceptions import RequestValidationError

class AppException(Exception):
    """应用异常基类"""
    def __init__(self, message: str, status_code: int = 400):
        self.message = message
        self.status_code = status_code

# backend/main.py

@app.exception_handler(AppException)
async def app_exception_handler(request: Request, exc: AppException):
    return JSONResponse(
        status_code=exc.status_code,
        content={"detail": exc.message}
    )

@app.exception_handler(RequestValidationError)
async def validation_exception_handler(request: Request, exc: RequestValidationError):
    return JSONResponse(
        status_code=status.HTTP_422_UNPROCESSABLE_ENTITY,
        content={"detail": "请求参数验证失败", "errors": exc.errors()}
    )
```

**优化效果：**
- 统一错误响应格式
- 更好的错误处理
- 便于调试和监控

```python
# backend/app/core/base_service.py

class BaseService:
    """基础服务类"""
    
    @staticmethod
    def get_by_id(db: Session, model_class, id: int):
        """根据ID获取记录"""
        return db.query(model_class).filter(model_class.id == id).first()
    
    @staticmethod
    def get_multi(db: Session, model_class, skip: int = 0, limit: int = 100):
        """获取列表"""
        query = db.query(model_class)
        total = query.count()
        items = query.offset(skip).limit(limit).all()
        return items, total
```

```python
# backend/app/core/logging.py

import logging
from logging.handlers import RotatingFileHandler
from pathlib import Path

def setup_logging():
    """配置日志系统"""
    log_dir = Path("logs")
    log_dir.mkdir(exist_ok=True)
    
    logging.basicConfig(
        level=logging.INFO,
        format='%(asctime)s - %(name)s - %(levelname)s - %(message)s',
        handlers=[
            RotatingFileHandler(
                log_dir / "app.log",
                maxBytes=10 * 1024 * 1024,  # 10MB
                backupCount=5
            ),
            logging.StreamHandler()
        ]
    )
```
