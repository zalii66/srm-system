# 查询优化问题修复说明

## 🔴 问题描述

数据库查询优化后，无法获取数据。

## 🔍 问题原因

1. **多对多关系不能使用 `joinedload` 嵌套**
   - `User.roles` 是多对多关系（通过 `user_role` 表）
   - `Role.permissions` 也是多对多关系（通过 `role_permission` 表）
   - 多对多关系必须使用 `selectinload`，不能使用 `joinedload` 嵌套

2. **`get_current_user` 使用了错误的加载策略**
   - 使用了 `joinedload(User.roles).joinedload(Role.permissions)`
   - 导致查询失败

## ✅ 修复方案

### 1. 修复 UserService 查询方法

**问题代码：**
```python
# 错误：多对多关系不能使用 joinedload 嵌套
query = db.query(User).options(
    joinedload(User.roles).joinedload(Role.permissions)
)
```

**修复后：**
```python
# 正确：使用 selectinload 处理多对多关系
from sqlalchemy.orm import selectinload
query = db.query(User).options(
    selectinload(User.roles).selectinload(Role.permissions)
)
```

### 2. 修复 get_current_user 函数

**问题代码：**
```python
# backend/app/core/deps.py
user = db.query(User).options(
    joinedload(User.roles).joinedload(Role.permissions)
).filter(User.username == token_data.sub).first()
```

**修复后：**
```python
# backend/app/core/deps.py
from sqlalchemy.orm import selectinload
user = db.query(User).options(
    selectinload(User.roles).selectinload(Role.permissions)
).filter(User.username == token_data.sub).first()
```

### 3. 修复 db_utils.py 工具函数

**修复内容：**
- `get_user_with_relations()` - 使用 `selectinload`
- `get_users_with_relations()` - 使用 `selectinload`
- 其他函数使用 `joinedload`（一对一或一对多关系）

## 🎯 关键知识点

### joinedload vs selectinload

1. **joinedload（JOIN 加载）**
   - 适用于：一对一、一对多关系
   - 使用 SQL JOIN 语句
   - 不能用于多对多关系的嵌套加载

2. **selectinload（SELECT IN 加载）**
   - 适用于：多对多关系、一对多关系
   - 使用独立的 SELECT 查询
   - 可以处理多对多关系的嵌套加载

### 关系类型判断

- **一对一关系：** 使用 `joinedload`
- **一对多关系：** 使用 `joinedload` 或 `selectinload`
- **多对多关系：** 必须使用 `selectinload`
