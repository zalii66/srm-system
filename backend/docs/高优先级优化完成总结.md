## 📝 使用示例

### 环境变量配置

```env
# .env 文件
DB_HOST=localhost
DB_PORT=3306
DB_USER=root
DB_PASSWORD=your_db_password
DB_NAME=srm_db
SECRET_KEY=your_secret_key_here

# 生产环境必须设置
DEFAULT_ADMIN_PASSWORD=your_strong_admin_password
```

### 权限检查使用

```python
from app.core.permissions import check_business_license_permission

# 检查营业执照文件权限
check_business_license_permission(db, current_user, year_month, filename)
```

### 异常处理使用

```python
from app.core.exceptions import NotFoundError, BusinessLogicError

# 抛出资源不存在异常
if not resource:
    raise NotFoundError("用户不存在")

# 抛出业务逻辑错误
if status == "completed":
    raise BusinessLogicError("已完成的项目不能修改")
```
