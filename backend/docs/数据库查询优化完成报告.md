### 2. UserService 查询优化 ✅

**优化内容：**
- ✅ `get_by_email()` - 添加 `joinedload(User.roles)` 预加载
- ✅ `get_multi()` - 添加 `joinedload(User.roles).joinedload(Role.permissions)` 预加载

**优化前：**
```python
def get_by_email(db: Session, email: str) -> Optional[User]:
    return db.query(User).filter(User.email == email).first()

def get_multi(...):
    query = db.query(User).options(joinedload(User.roles))
```

**优化后：**
```python
def get_by_email(db: Session, email: str) -> Optional[User]:
    return db.query(User).options(joinedload(User.roles)).filter(User.email == email).first()

def get_multi(...):
    query = db.query(User).options(
        joinedload(User.roles).joinedload(Role.permissions)
    )
```

**效果：**
- 减少查询次数：从 N+1 次减少到 1-2 次
- 预加载角色和权限，避免延迟加载

### 3. SupplierService 查询优化 ✅

**优化内容：**
- ✅ `get_by_id()` - 添加 `joinedload(Supplier.user)` 和 `joinedload(Supplier.audit_user)` 预加载
- ✅ `get_by_user_id()` - 添加关联数据预加载

**优化前：**
```python
def get_by_id(db: Session, supplier_id: int) -> Optional[Supplier]:
    return db.query(Supplier).filter(Supplier.id == supplier_id).first()

def get_by_user_id(...):
    supplier = db.query(Supplier).filter(Supplier.user_id == user_id).first()
```

**优化后：**
```python
def get_by_id(db: Session, supplier_id: int) -> Optional[Supplier]:
    return db.query(Supplier).options(
        joinedload(Supplier.user),
        joinedload(Supplier.audit_user)
    ).filter(Supplier.id == supplier_id).first()

def get_by_user_id(...):
    supplier = db.query(Supplier).options(
        joinedload(Supplier.user),
        joinedload(Supplier.audit_user)
    ).filter(Supplier.user_id == user_id).first()
```

**效果：**
- 减少查询次数：从 3 次减少到 1 次
- 预加载用户和审核人信息
