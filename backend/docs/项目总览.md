## 🚀 快速开始

### 第一步：安装环境（Windows）

双击运行：
```
setup.bat
```

### 第二步：配置数据库

1. 确保MySQL正在运行
2. 在 `backend` 目录创建 `.env` 文件
3. 复制以下内容到 `.env`：

```env
# 数据库配置
DB_HOST=127.0.0.1
DB_PORT=3306
DB_USER=root
DB_PASSWORD=root
DB_NAME=srm

# JWT配置
SECRET_KEY=your-secret-key-change-in-production-09876543210987654321
ALGORITHM=HS256
ACCESS_TOKEN_EXPIRE_MINUTES=30

# 应用配置
PROJECT_NAME=SRM供应商管理系统
VERSION=1.0.0
API_V1_STR=/api/v1
DEBUG=True
```

### 第三步：初始化数据库

双击运行：
```
init_db.bat
```

### 第四步：启动服务

双击运行：
```
run.bat
```

### 第五步：测试API

浏览器访问：
```
http://localhost:8000/api/v1/docs
```

使用默认账号登录：
- 用户名：`admin`
- 密码：`admin`

## 📊 数据库设计

### 表结构

**users (用户表)**
```sql
id              INT         主键
username        VARCHAR(50) 唯一，用户名
email           VARCHAR(100)唯一，邮箱
hashed_password VARCHAR(255)密码哈希
full_name       VARCHAR(100)全名
phone           VARCHAR(20) 手机号
is_active       BOOLEAN     是否激活
is_superuser    BOOLEAN     是否超级管理员
created_at      DATETIME    创建时间
updated_at      DATETIME    更新时间
last_login      DATETIME    最后登录
```

**roles (角色表)**
```sql
id          INT         主键
name        VARCHAR(50) 唯一，角色名
code        VARCHAR(50) 唯一，角色编码
description TEXT        角色描述
is_active   BOOLEAN     是否激活
created_at  DATETIME    创建时间
updated_at  DATETIME    更新时间
```

**permissions (权限表)**
```sql
id          INT         主键
name        VARCHAR(50) 唯一，权限名
code        VARCHAR(50) 唯一，权限编码
resource    VARCHAR(100)资源
action      VARCHAR(50) 操作
description TEXT        权限描述
is_active   BOOLEAN     是否激活
created_at  DATETIME    创建时间
updated_at  DATETIME    更新时间
```

**user_role (用户角色关联)**
```sql
user_id     INT 用户ID（外键）
role_id     INT 角色ID（外键）
```

**role_permission (角色权限关联)**
```sql
role_id       INT 角色ID（外键）
permission_id INT 权限ID（外键）
```

### RBAC关系图

```
       ┌─────────┐
       │  User   │ 用户
       └────┬────┘
            │ N:M
       ┌────┴────┐
       │user_role│ 用户角色关联
       └────┬────┘
            │ N:M
       ┌────┴────┐
       │  Role   │ 角色
       └────┬────┘
            │ N:M
   ┌────────┴────────────┐
   │ role_permission     │ 角色权限关联
   └────────┬────────────┘
            │ N:M
     ┌──────┴──────┐
     │ Permission  │ 权限
     └─────────────┘
```

## 🔐 API接口清单

### 认证接口 `/api/v1/auth`

| 方法 | 路径 | 功能 | 认证 |
|------|------|------|------|
| POST | `/login` | 用户登录 | ❌ |
| GET | `/me` | 获取当前用户信息 | ✅ |
| POST | `/logout` | 用户登出 | ✅ |

### 用户接口 `/api/v1/users`

| 方法 | 路径 | 功能 | 权限 |
|------|------|------|------|
| GET | `/` | 获取用户列表（分页） | 超级管理员 |
| GET | `/{user_id}` | 获取用户详情 | 本人或管理员 |
| POST | `/` | 创建新用户 | 超级管理员 |
| PUT | `/{user_id}` | 更新用户信息 | 本人或管理员 |
| DELETE | `/{user_id}` | 删除用户 | 超级管理员 |

### 角色接口 `/api/v1/roles`

| 方法 | 路径 | 功能 | 权限 |
|------|------|------|------|
| GET | `/` | 获取角色列表（分页） | 超级管理员 |
| GET | `/{role_id}` | 获取角色详情 | 超级管理员 |
| POST | `/` | 创建新角色 | 超级管理员 |
| PUT | `/{role_id}` | 更新角色信息 | 超级管理员 |
| DELETE | `/{role_id}` | 删除角色 | 超级管理员 |
