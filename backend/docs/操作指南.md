## 🔄 业务流程更新

### 完整的项目流程（带公司和品牌）

```
1. 管理员创建公司（分公司）
   POST /api/v1/companies/

2. 管理员创建品牌
   POST /api/v1/brands/

3. 项目经理创建项目（选择所属公司）
   POST /api/v1/projects/
   - 指定 company_id

4. 项目经理发布项目
   POST /api/v1/projects/{id}/publish

5. 供应商注册并审核
   POST /api/v1/suppliers/register
   POST /api/v1/suppliers/{id}/audit

6. 供应商报价（选择品牌）
   POST /api/v1/quotations/
   - 在items中指定 brand_id
   - 自动创建 supplier_project_history 记录

7. 供应商提交报价
   POST /api/v1/quotations/{id}/submit

8. 项目经理评审报价
   POST /api/v1/quotations/{id}/evaluate
   - 如果中标，自动更新 supplier_project_history.is_winner=1

9. 项目完成后，项目经理评价供应商
   PUT /api/v1/supplier_project_history/{id}
   - 更新评分和评价
```

## 📋 常用API接口清单

### 公司管理 API

| 接口 | 说明 |
|------|------|
| `GET /api/v1/companies/` | 获取公司列表 |
| `GET /api/v1/companies/{id}` | 获取公司详情 |
| `POST /api/v1/companies/` | 创建公司 |
| `PUT /api/v1/companies/{id}` | 更新公司 |
| `DELETE /api/v1/companies/{id}` | 删除公司 |

### 品牌管理 API

| 接口 | 说明 |
|------|------|
| `GET /api/v1/brands/` | 获取品牌列表 |
| `GET /api/v1/brands/{id}` | 获取品牌详情 |

| `PUT /api/v1/brands/{id}` | 更新品牌 |
| `DELETE /api/v1/brands/{id}` | 删除品牌 |

## 💡 使用建议

### 1. 公司数据管理
- 建议先创建所有分公司数据
- 设置合理的排序顺序
- 填写完整的联系信息

### 2. 品牌数据管理
- 建议按类别组织品牌
- 标记常用品牌为"推荐"
- 定期更新品牌信息

### 3. 项目管理
- 创建项目时务必选择所属公司
- 这样便于统计各分公司的项目情况

### 4. 报价管理
- 鼓励供应商选择已有品牌
- 有助于数据规范化和统计分析

## ❓ 常见问题

### Q1: 已有旧数据如何处理？
**A**: 建议重新初始化数据库，或使用Alembic进行数据迁移

### Q2: 项目可以不选择公司吗？
**A**: 可以，`company_id` 是可选字段，但建议填写

### Q3: 报价必须选择品牌吗？
**A**: 不必须，可以手动输入品牌名称

### Q4: 如何查看供应商的历史项目？
**A**: 查询 `supplier_project_history` 表，或通过API获取
