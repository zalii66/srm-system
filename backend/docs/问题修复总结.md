# 问题修复总结

## 🔴 发现的问题

1. **语法错误（IndentationError）**
   - **位置：** `backend/app/services/milestone_service.py:284`
   - **错误：** `unexpected indent`
   - **原因：** 代码缩进错误，导致后端服务无法启动
   - **影响：** 所有 API 请求都超时（因为后端根本没启动）

2. **查询超时问题**
   - **位置：** 供应商列表查询
   - **原因：** 
     - 过度预加载权限数据
     - 嵌套 `selectinload` 导致多次查询
   - **影响：** 查询响应时间过长，导致30秒超时

## ✅ 修复内容

### 1. 修复语法错误

**文件：** `backend/app/services/milestone_service.py`

**修复前：**
```python
if not project:
    from sqlalchemy.orm import joinedload
project = db.query(Project).options(...).first()
    if not project:  # 缩进错误
        raise HTTPException(...)
```

**修复后：**
```python
if not project:
    from sqlalchemy.orm import joinedload
    project = db.query(Project).options(...).first()
    if not project:  # 正确的缩进
        raise HTTPException(...)
```

### 2. 优化查询性能

**原则：** 按需加载，避免过度预加载

#### 2.1 优化用户查询

**文件：** `backend/app/services/user_service.py`

- 移除嵌套的 `selectinload`
- 只加载角色，不加载权限
- 权限按需加载

**修复前：**
```python
selectinload(User.roles).selectinload(Role.permissions)
```

**修复后：**
```python
selectinload(User.roles)
```

#### 2.2 优化 get_current_user

**文件：** `backend/app/core/deps.py`

- 每次请求只加载角色
- 权限按需加载

#### 2.3 优化工具函数

**文件：** `backend/app/core/db_utils.py`

- `get_user_with_relations()`: 只加载角色
- `get_users_with_relations()`: 只加载角色

## ⚠️ 注意事项

### 权限检查

如果代码中需要检查权限：

1. **大多数权限检查只需要角色代码：**
   ```python
   is_supplier = any(role.code == "supplier" for role in user.roles)
   ```

2. **需要完整权限列表时，可以单独查询：**
   ```python
   role = db.query(Role).options(
       selectinload(Role.permissions)
   ).filter(Role.code == "supplier").first()
   ```
