# 报价详情页操作按钮完善说明

## ✅ 完成的功能

### 1. 操作按钮位置优化

**修改前：**
- 评审操作按钮位于报价明细卡片底部
- 顶部操作区域缺少管理员操作按钮

**修改后：**
- 所有操作按钮统一在页面顶部操作区域显示
- 根据用户角色和报价状态动态显示相应按钮

### 2. 供应商操作按钮

根据报价状态显示：

| 状态 | 可用操作 |
|------|---------|
| 草稿 (draft) | 提交报价、编辑报价、取消报价 |
| 已提交 (submitted) | 取消报价 |
| 其他状态 | 无操作 |

### 3. 项目经理/管理员操作按钮

#### 3.1 评审操作

| 状态 | 可用操作 |
|------|---------|
| 已提交 (submitted) | 批准（中标）、拒绝（未中标） |
| 已中标 (selected) | 重新评审（可改为未中标） |
| 已拒绝 (rejected) | 重新评审（可改为中标） |

#### 3.2 管理员特殊操作

- 管理员可以取消任何状态的报价（已取消状态除外）

### 4. 重新评审功能

**功能说明：**
- 支持对已中标或已拒绝的报价进行重新评审
- 重新评审时保留原有评审意见作为默认值
- 评审对话框标题会显示"重新评审"提示

**后端支持：**
- 修改了 `QuotationService.evaluate()` 方法
- 允许对 `submitted`、`selected`、`rejected` 状态的报价进行评审

## 🎯 操作流程

### 供应商流程

1. **创建报价** → 状态：草稿
2. **编辑报价** → 可以修改报价内容
3. **提交报价** → 状态：已提交（无法再修改）
4. **取消报价** → 状态：已取消

### 项目经理/管理员流程

1. **查看已提交的报价** → 显示"批准（中标）"和"拒绝（未中标）"按钮
2. **评审报价** → 选择中标或未中标，填写评审意见
3. **重新评审** → 对已评审的报价可以重新评审，修改评审结果

## 🔒 权限控制

### 供应商权限

- 只能操作自己的报价
- 只能取消草稿或已提交状态的报价

### 项目经理权限

- 只能评审自己项目的报价
- 可以对已提交、已中标、已拒绝的报价进行评审

### 管理员权限

- 可以评审所有报价
- 可以取消任何状态的报价（已取消除外）
- 拥有所有操作权限

## 💡 使用说明

### 评审报价

1. 点击"批准（中标）"或"拒绝（未中标）"按钮
2. 在弹出的对话框中填写评审意见（必填）
3. 点击"确定"完成评审

### 重新评审

1. 对于已中标或已拒绝的报价，点击"重新评审"按钮
2. 系统会自动切换评审状态（中标→未中标，未中标→中标）
3. 可以修改评审意见
4. 点击"确定"完成重新评审
