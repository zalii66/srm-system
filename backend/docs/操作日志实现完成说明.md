## 📊 操作日志记录的操作类型

| 操作类型 | 说明 | 记录位置 |
|---------|------|---------|
| create | 创建资源 | 项目创建、报价创建 |
| update | 更新资源 | 项目更新、发布 |
| delete | 删除资源 | 项目删除 |
| audit | 审核操作 | 供应商审核 |
| evaluate | 评审操作 | 报价评审 |
| submit | 提交操作 | 报价提交 |
| cancel | 取消操作 | 报价取消 |

## 🔍 日志记录的信息

- **用户信息**：用户ID、用户名
- **操作信息**：操作类型、资源类型、资源ID、资源名称、操作描述
- **变更信息**：旧值、新值（JSON格式）
- **请求信息**：IP地址、User-Agent、请求方法、请求路径
- **时间信息**：操作时间

## 🚀 使用说明

### 后端使用

在需要记录操作日志的地方调用 `log_operation()` 函数：

```python
from app.utils.operation_log import log_operation

# 在 API 端点中记录日志
log_operation(
    db=db,
    request=request,
    user_id=current_user.id,
    username=current_user.username,
    action="create",
    resource_type="project",
    resource_id=project.id,
    resource_name=project.project_name,
    description=f"创建项目：{project.project_name}"
)
```

### 前端使用

1. **查看操作日志**：
   - 登录系统（管理员）
   - 点击左侧菜单"操作日志"
   - 可以按条件筛选查看日志

2. **查看日志详情**：
   - 在日志列表中点击"查看详情"
   - 可以查看完整的日志信息，包括旧值和新值

3. **清理旧日志**：
   - 点击"清理旧日志"按钮
   - 设置保留天数（默认90天）
   - 系统将删除指定天数之前的所有日志

## 📝 后续优化建议

1. **异步记录日志**：可以考虑使用异步任务队列（如 Celery）来记录日志，避免影响主业务流程性能

3. **日志统计分析**：添加日志统计分析功能（操作趋势、用户行为分析等）

4. **日志告警**：对于重要操作（如删除），可以添加告警通知

5. **更多操作记录**：可以扩展记录更多操作（用户管理、角色管理、权限管理等）
