### 2. **日志系统** (#13) ✅

**优化内容：**
- ✅ 创建了 `backend/app/core/logging.py` 日志配置模块
- ✅ 支持文件日志（带轮转）和控制台输出
- ✅ 分离错误日志和普通日志
- ✅ 在 `main.py` 中集成日志系统

**功能特性：**
- 日志文件保存在 `logs/` 目录
- 日志文件自动轮转（10MB，保留5个备份）
- 支持 DEBUG/INFO/WARNING/ERROR 级别
- 错误日志单独记录到 `error.log`
- 控制台输出用于开发调试

**使用方式：**
```python
from app.core.logging import get_logger

logger = get_logger(__name__)
logger.info("操作成功")
logger.error("操作失败")
```

**优化效果：**
- 便于问题排查和调试
- 支持生产环境监控
- 提高系统可观测性

## 📝 使用说明

### 数据库索引优化

**首次执行：**
```bash
cd backend
python optimize_database.py
```

**说明：**
- 脚本会直接连接数据库（127.0.0.1:3306，用户：root，密码：root）
- 如果索引已存在，会自动跳过
- 可以安全地重复执行

**手动执行SQL（可选）：**
```bash
mysql -u root -proot srm < backend/migrations/add_indexes.sql
```

### 日志查看
