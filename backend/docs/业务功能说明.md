# SRM供应商管理系统 - 业务功能说明

## 📋 系统概述

本系统是一个完整的供应商关系管理（SRM）系统，支持招标项目管理、供应商管理和报价管理。

## 👥 用户角色

### 1. 管理员（Admin）
**角色代码**: `admin`  
**权限**: 拥有所有权限

**功能：**
- ✅ 管理所有用户
- ✅ 审核供应商资质
- ✅ 查看所有项目
- ✅ 查看所有报价
- ✅ 管理角色和权限

### 2. 项目经理（Project Manager）
**角色代码**: `project_manager`  
**描述**: 分公司项目负责人

**功能：**
- ✅ 创建招标项目
- ✅ 编辑自己的项目
- ✅ 删除自己的项目
- ✅ 发布项目（供应商可见）
- ✅ 管理项目明细
- ✅ 查看项目的所有报价
- ✅ 评审报价（中标/未中标）

### 3. 供应商（Supplier）
**角色代码**: `supplier`  
**描述**: 外部供应商

**注册流程：**
1. 自行注册（填写公司信息、联系人、手机号、密码）
2. 登录后上传公司资质文件
3. 等待管理员审核
4. 审核通过后可查看项目并报价

**功能：**
- ✅ 查看已发布的招标项目
- ✅ 创建报价单
- ✅ 编辑报价（仅草稿状态）
- ✅ 提交报价
- ✅ 查看自己的报价历史

**限制：**
- ❌ 资质未审核通过前无法查看项目
- ❌ 无法查看其他供应商的报价
- ❌ 已提交的报价不能修改

## 🔄 业务流程

### 供应商注册与审核流程

```
1. 供应商注册
   POST /api/v1/suppliers/register
   {
     "username": "supplier01",
     "password": "password123",
     "company_name": "ABC公司",
     "contact_person": "张三",
     "contact_phone": "13800138000",
     "company_address": "北京市朝阳区...",
     "business_scope": "建筑材料销售"
   }

2. 登录获取Token
   POST /api/v1/auth/login
   
3. 上传资质文件
   POST /api/v1/suppliers/me/qualification
   {
     "file_ids": [1, 2, 3]
   }

4. 管理员审核
   POST /api/v1/suppliers/{id}/audit
   {
     "status": "approved",
     "audit_comment": "资质齐全，审核通过"
   }

5. 供应商现在可以查看项目了
```

### 供应商报价流程

```
3. 供应商创建报价

         "model": "525#",
         "origin": "安徽"

         "quantity": 50,

5. 项目经理查看报价
   GET /api/v1/quotations/?project_id=1

6. 项目经理评审报价
   POST /api/v1/quotations/{id}/evaluate
   {
     "status": "selected",
     "evaluation_comment": "价格合理，质量可靠，中标"
   }
```

## 📊 数据库表结构

### suppliers（供应商表）
```sql
- id: 主键
- user_id: 关联用户ID
- company_name: 公司名称
- contact_person: 联系人
- contact_phone: 联系电话
- company_address: 公司地址
- business_scope: 经营范围
- qualification_docs: 资质文件（JSON）
- status: 审核状态（pending/approved/rejected/suspended）
- audit_user_id: 审核人ID
- audit_time: 审核时间
- audit_comment: 审核意见
```

### projects（项目表）
```sql
- id: 主键
- project_no: 项目编号（自动生成）
- project_name: 项目名称
- description: 项目描述
- category: 项目类别
- budget: 项目预算
- location: 项目地点
- start_date: 开始时间
- end_date: 结束时间
- bidding_deadline: 投标截止时间
- status: 项目状态（draft/published/bidding/evaluation/completed/cancelled）
- creator_id: 创建人ID（项目经理）
- branch_office: 分公司名称
- attachments: 附件（JSON）
```

### project_items（项目明细表）
```sql
- id: 主键
- project_id: 项目ID
- item_no: 明细编号
- item_name: 明细名称
- specification: 规格型号
- unit: 单位
- quantity: 数量
- estimated_price: 预估单价
- description: 说明
```

### quotations（报价表）
```sql
- id: 主键
- quotation_no: 报价单号（自动生成）
- project_id: 项目ID
- supplier_id: 供应商ID
- total_amount: 报价总金额
- tax_rate: 税率
- delivery_days: 交货天数
- payment_terms: 付款条件
- warranty_period: 质保期
- status: 状态（draft/submitted/selected/rejected/cancelled）
- submitted_at: 提交时间
- evaluated_by: 评审人ID
- evaluated_at: 评审时间
- evaluation_comment: 评审意见
```

### quotation_items（报价明细表）
```sql
- id: 主键
- quotation_id: 报价ID
- project_item_id: 项目明细ID
- unit_price: 单价
- quantity: 数量
- amount: 金额
- brand: 品牌
- model: 型号
- origin: 产地
- remarks: 备注
```

## 🚀 API接口清单

### 供应商管理 `/api/v1/suppliers`

| 方法 | 路径 | 功能 | 权限 |
|------|------|------|------|
| POST | `/register` | 供应商注册 | 公开 |
| GET | `/` | 获取供应商列表 | 管理员 |
| GET | `/me` | 获取当前供应商信息 | 供应商 |
| PUT | `/me` | 更新供应商信息 | 供应商 |
| POST | `/me/qualification` | 上传资质文件 | 供应商 |
| POST | `/{id}/audit` | 审核供应商 | 管理员 |
| GET | `/{id}` | 获取供应商详情 | 管理员/本人 |

### 项目管理 `/api/v1/projects`

| 方法 | 路径 | 功能 | 权限 |
|------|------|------|------|
| POST | `/` | 创建项目 | 项目经理 |
| GET | `/` | 获取项目列表 | 所有已登录用户* |
| GET | `/{id}` | 获取项目详情 | 所有已登录用户* |
| PUT | `/{id}` | 更新项目 | 项目经理（仅自己的） |
| DELETE | `/{id}` | 删除项目 | 项目经理（仅自己的） |
| POST | `/{id}/publish` | 发布项目 | 项目经理（仅自己的） |

### 报价管理 `/api/v1/quotations`

| 方法 | 路径 | 功能 | 权限 |
|------|------|------|------|
| POST | `/` | 创建报价 | 供应商 |
| GET | `/` | 获取报价列表 | 项目经理/供应商* |
| GET | `/my` | 获取我的报价 | 供应商 |
| GET | `/{id}` | 获取报价详情 | 项目经理/供应商* |
| PUT | `/{id}` | 更新报价 | 供应商（仅草稿） |
| POST | `/{id}/submit` | 提交报价 | 供应商 |
| POST | `/{id}/evaluate` | 评审报价 | 项目经理 |

## 📝 使用示例

### 1. 供应商完整注册流程

```bash
# 1. 注册
curl -X POST "http://localhost:8000/api/v1/suppliers/register" \
  -H "Content-Type: application/json" \
  -d '{
    "username": "supplier_abc",
    "password": "Abc@123456",
    "company_name": "ABC科技有限公司",
    "contact_person": "李经理",
    "contact_phone": "13900139000",
    "company_address": "上海市浦东新区张江高科技园区",
    "business_scope": "电子产品、软件开发"
  }'

# 2. 登录
curl -X POST "http://localhost:8000/api/v1/auth/login" \
  -d "username=supplier_abc&password=Abc@123456"

# 3. 上传资质（需要token）
curl -X POST "http://localhost:8000/api/v1/suppliers/me/qualification" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "file_ids": [1, 2, 3]
  }'
```

### 2. 项目经理创建并发布项目

```bash
# 1. 创建项目
curl -X POST "http://localhost:8000/api/v1/projects/" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "project_name": "2025年办公设备采购",
    "description": "采购办公电脑、打印机等设备",
    "category": "办公设备",
    "budget": 500000.00,
    "location": "北京总部",
    "bidding_deadline": "2025-12-01T00:00:00",
    "branch_office": "北京分公司",
    "items": [
      {
        "item_no": "001",
        "item_name": "台式电脑",
        "specification": "i5处理器/8G内存/256G固态",
        "unit": "台",
        "quantity": 50,
        "estimated_price": 4000.00
      }
    ]
  }'

# 2. 发布项目
curl -X POST "http://localhost:8000/api/v1/projects/1/publish" \
  -H "Authorization: Bearer YOUR_TOKEN"
```

### 3. 供应商报价

```bash
# 1. 查看项目
curl -X GET "http://localhost:8000/api/v1/projects/" \
  -H "Authorization: Bearer SUPPLIER_TOKEN"

# 2. 创建报价
curl -X POST "http://localhost:8000/api/v1/quotations/" \
  -H "Authorization: Bearer SUPPLIER_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "project_id": 1,
    "tax_rate": 0.13,
    "delivery_days": 15,
    "payment_terms": "款到发货",
    "warranty_period": "3年",
    "items": [
      {
        "project_item_id": 1,
        "unit_price": 3800.00,
        "quantity": 50,
        "brand": "联想",
        "model": "启天M428",
        "origin": "中国"
      }
    ]
  }'

# 3. 提交报价
curl -X POST "http://localhost:8000/api/v1/quotations/1/submit" \
  -H "Authorization: Bearer SUPPLIER_TOKEN"
```

3. 供应商只能看到已发布的项目
