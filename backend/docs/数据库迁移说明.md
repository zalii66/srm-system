# 数据库迁移说明

## 问题
供应商表（suppliers）缺少以下字段，导致序列化失败（500错误）：
- `tax_number` (公司税号)
- `bank_name` (开户行)
- `bank_account` (银行账号)

## 解决方案

### 方法1：使用SQL脚本（推荐）

在MySQL客户端执行以下SQL：

```sql
-- 添加tax_number字段
ALTER TABLE suppliers 
ADD COLUMN tax_number VARCHAR(50) NULL COMMENT '公司税号' AFTER company_name;

-- 添加bank_name字段
ALTER TABLE suppliers 
ADD COLUMN bank_name VARCHAR(200) NULL COMMENT '开户行' AFTER business_scope;

-- 添加bank_account字段
ALTER TABLE suppliers 
ADD COLUMN bank_account VARCHAR(50) NULL COMMENT '银行账号' AFTER bank_name;

-- 更新现有字段注释
ALTER TABLE suppliers 
MODIFY COLUMN company_address VARCHAR(500) NULL COMMENT '注册地址';

ALTER TABLE suppliers 
MODIFY COLUMN business_scope TEXT NULL COMMENT '主营产品';
```

### 方法2：使用命令行

```bash
mysql -h 127.0.0.1 -u root -proot srm < add_supplier_fields.sql
```

### 方法3：在MySQL Workbench中执行

打开 `backend/add_supplier_fields.sql` 文件，在MySQL Workbench中执行。

## 执行后验证

执行迁移后，重启后端服务，供应商列表API应该可以正常工作了。
